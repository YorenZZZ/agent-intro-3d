# Codex Intro 3D 版本记录

## 1.3.0（构建 6）— 2026-10-13

### 随机闲聊

- 新增 100 条本地机械师女孩台词，打乱轮流抽取，一轮结束前不重复，轮次交界也避免相邻重复。
- 人物显示时随机等待 45–90 秒，气泡停留 7 秒；沿用额度气泡的黑橙面板与位置，闲聊穿透鼠标。
- 额度优先显示；人物隐藏或重新入场时取消闲聊，恢复显示后重新计时。
- 根据窗口裁切和动作轮廓预留空间，空间不足时不显示闲聊，避免挡住人物。

### 入场与动作衔接

- 完整播放下降、着地姿势、起身和转身；交接到侧栏后才开始 5 秒站立待机，再允许随机动作自然接入。
- 入场期间预缓冲待机视频，确认首帧实际呈现后撤去落地画面；慢解码时使用站立海报兜底。
- 落地阴影跟随视频帧时间，离屏录制与实际播放使用相同时间轴。
- 随机动作排除上一次实际播放的动作，经过待机、点击插队或重新入场也保留记录；显式指定动作仍可重播。
- 修复换片期间将已播放片段重新入队的问题，处理隐藏、恢复与异步回调的交接状态。

### 跳过与验证入口

- 读取当前 Codex 进程的主界面就绪事件，确认界面加载完成后才显示 Esc 提示并允许跳过。
- 宠物快照新增 `--chatter` 和 `--entrance`，分别预览闲聊切换额度与入场首帧交接。
- 补充闲聊、完整落地、首帧等待、动作去重和主界面就绪检测的回归测试。
